# Exploratory Data Analysis (EDA) with Pandas Profiling

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python to understand dataset structure, identify data quality issues, and discover meaningful patterns.

Using Pandas, I explored the dataset by examining its dimensions, data types, summary statistics, and missing values. I also used Pandas Profiling to generate a detailed automated analysis report, making it easier to understand variable distributions, correlations, and potential data-quality issues.

## 🛠️ Technologies Used
- Python
- Pandas
- Pandas Profiling
- Jupyter Notebook

## 🎯 Key Learnings
- Understanding dataset structure and data types
- Identifying missing values and duplicate records
- Analyzing statistical summaries and data distributions
- Exploring relationships and correlations between variables
- Generating automated EDA reports using Pandas Profiling

## 📈 Project Objective

The objective of this project is to strengthen my data analysis skills and understand how EDA helps prepare data for further analysis and data-driven decision-making.

## 🚀 Conclusion

This project helped me gain practical experience in data exploration and automated profiling. It is another step in my continuous learning journey toward becoming a skilled Data Analyst and Data Scientist.
